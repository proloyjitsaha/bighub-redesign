# BigHub Boys Collection — Modern B2B Redesign

> **High-end wholesale & factory-direct presentation for BigHub (Truehub Apparels, Howrah, India)**
> Crafted with fluid motion design, Lenis inertial momentum scrolling, interactive 3D product cards, and authentic BigHub branding.

---

## ✨ Features & Architecture

* **Visual Identity & Rhythm**:
  * Cloned motion rhythm and cinematic flow inspired by modern high-end interactive fashion platforms.
  * Light theme palette (`#fbfbfe` surface with Electric Magenta `#e00885` and Royal Indigo `#3d2b9b` accents).
  * Authentic typography using **Graphik** (`Graphik-Bold`, `Graphik-Semibold`, `Graphik-Light`).
  * 3D rotating disc logo in the top center with dual-sided upright orientation.

* **Motion & Animation Physics**:
  * **Lenis Smooth Inertial Momentum**: Exponential smooth scroll easing.
  * **Interactive 3D Card Physics**: Mouse-reactive perspective tilt (`translateZ`, `rotateX/Y`) with dynamic specular glare and dual-color shadows.
  * **Bidirectional Wave Reveals**: Sinusoidal staggered entrance animations on sections and product cards that cleanly reset upon scrolling back to top and smoothly re-trigger on subsequent downward scrolls.
  * **Velocity-Reactive Canvas Textile Mesh**: Real-time fluid sine-wave cloth simulation reacting dynamically to scroll acceleration.

* **Product Catalog & Sizing**:
  * **37 Authentic Baba Suit & Double Top Sets**: High-resolution studio photography from BigHub.
  * **Portrait 3:4 Proportions**: Fully uncropped vertical framing (`aspect-ratio: 3 / 4; object-position: center top`) ensuring 100% face and headroom visibility.
  * **B2B Wholesale WhatsApp Inquiry**: Direct pre-filled WhatsApp quotation generator for instant bulk inquiries.

## 🚀 Quick Start / Local Preview

1. **Clone or Download**:
   ```bash
   git clone https://github.com/proloyjitsaha/bighub-redesign.git
   cd bighub-redesign
   ```

2. **Launch Local Server**:
   ```bash
   python -m http.server 8080
   ```

3. **Open in Browser**:
   Visit [http://localhost:8080](http://localhost:8080).
